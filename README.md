# No Nonsense Fitness

A static, single-page marketing website for No Nonsense Fitness, promoting Jason Sutherland's online and in-person personal training in Leith, Edinburgh.

## File structure

- `index.html` — page content, SEO metadata, structured data, and social links.
- `styles.css` — responsive styling for desktop and mobile.
- `assets/` — brand mark and photography used by the page.

## Preview and deploy

Open `index.html` in a browser for a local preview, or run `python3 -m http.server` from this directory and visit the address it displays. The production site is deployed with GitHub Pages from the `main` branch at `https://doonleith.github.io/no-nonsense-fitness/`; pushing changes to `main` republishes the site.
